# pmaxis

The Data Layer for Prediction Markets.

Structured prediction-market data, WebSocket streams, REST APIs, and signals for trading systems, analytics, and AI agents.

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- GSAP + ScrollTrigger + Lenis
- Three.js / Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
